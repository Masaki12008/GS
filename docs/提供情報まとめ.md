# 若穂地区 小中学校再編検討 ― 提供情報まとめ

作成日：2026年10月27日（R8）

## 1. 検討の背景（最初にいただいた情報）

- 地域の少子化への対応を検討するため、住民説明会を予定している。
- 長野市若穂地区の小学校は、綿内小・川田小・保科小の3校。
- 当初の概数は次のとおり。※推計表の実数（下記3）に置き換えること。
  - 綿内小：全校約270名、1学年約2クラス
  - 川田小：約180〜200名、1学年1クラス
  - 保科小：全校約70名、2026年度（R8）の1年生は2人
- 今後さらに少子化が進むと見込まれる。
- 再編、統合、一部統合、現状維持などの選択肢から最適なものを選び、地域として長野市へ提言したい。
- 求めた支援：コンサルとして、スケジュール感の分かるロードマップを作ること。

出典：長野市教育委員会事務局総務課。https://www.city.nagano.nagano.jp/documents/1877/01gakko.pdf
- 2026年11月4日に市のサイトから全60ページを取得した（`input/city/長野市学校施設長寿命化計画_R5改訂_本文_市サイト.pdf`）。以前のSafari保存版で欠けていたページ（本文p17・24・32・40、施設一覧の147〜195行目）も、このPDFで確認できる。

  - 令和2年度、市内小学校54校のうち国の基準・県の方針をすべて満たすのは13校（24.1％）、すべて満たさないのは16校（29.6％）。中学校24校では12校（50％）と7校（29.2％）。

  - 「できる限り地域に学校を残したいという地域の思いも受け止めつつ」、小学校の低・中学年は地域で学び、高学年以上は大規模な学校で学ぶことを検討する必要がある。
  - 他の公共施設との複合化・多機能化も合わせて検討する。
- **総合管理計画との関係**：公共施設の総量を今後20年間で20％縮減する目標（学校に限らない市の公共施設全体）。

### 本文に書かれている改修の周期（p32〜33）

- 目標使用年数は80年（市の公共施設等総合管理計画にあわせる）。旧耐震の建物は、それまでの改修の状況などを勘案し、80年使えるかを耐力度調査の結果で個別に判断する。
- 予防保全的な大規模改修（内外装・設備の改修や更新）は、建設から20年と60年が目安。
- 建設から40年後に長寿命化改修（躯体の中性化対策、給排水配管の更新、省エネ化など）を行い、その後40年程度使う。
- 改修する建物の名前は計画に書かず、随時決める（p44）。施設整備の優先順位は、健全度が低く古い施設から（p40）。

### 「期間中に改修・更新を迎える年度」の決め方（添付資料の全小中学校81施設を照らし合わせた結果）

本文にも添付資料にも、計算方法の説明はない。全81施設の行を並べると、次の規則に当てはまる施設がほとんどだった。

- **新耐震の施設**：計画期間（2021〜2030年度）中に築20年または築40年を迎える19施設は、すべて「建築年度＋20」または「＋40」の年度で、内容も「20」「40」。期間中に該当しない施設は「―」。
- **旧耐震の施設**：内容は「更新」（34施設）。そのうち30施設は「建築年度＋50」の年度（築50年ちょうど）。すでに築50年を過ぎていた4施設（城山・鍋屋田・寺尾・芹田小）は2029〜2030年度。築50年を過ぎた「経過」が3施設。
- **例外**：旧耐震で期間中に築50年を迎えるのに「―」になっている施設が12（朝陽・徳間・芋井・安茂里・篠ノ井東・信里・塩崎・清野・西条・七二会・信更小、戸隠中）。新耐震でも三陽中（1983年度、築40年は2023年度）は「―」。理由は書かれていない。

### 7の質問（なぜ若穂中・保科小は20年周期どおりで、川田小・綿内小は築50年で「更新」なのか）への答え

**分かったこと**

- 学校ごとに個別に判断した結果ではなく、**その施設の「最も大きい棟」が新耐震か旧耐震か**で、市内の学校がほぼ一律に振り分けられている。
  - 新耐震（若穂中・保科小）なら、築20年・40年の改修の年度が入る。
  - 旧耐震（川田小・綿内小）なら、築50年の年度に「更新」が入る。
- 年度と内容は、学校全体ではなく1つの棟についてのもの。たとえば綿内小の行は1980年度（北校舎）だが、本文の一覧では南校舎（1972年度）のほうが古く、面積も大きい。
- **保科小の行は、本文の一覧と食い違って見える。** 添付資料では「RC造・2010年度・新耐震」だが、本文の一覧で2010年度の建物は体育館（S造・853㎡）だけで、校舎は1977〜1999年度（南校舎・北校舎は旧耐震）。校舎を基準にすれば、川田小・綿内小と同じ「更新」の扱いになった可能性がある。

- 改修する建物の名前と時期は計画に書かれておらず、随時決める。添付資料の年度は「工事の予定」ではない。

**分からないこと**

- 12施設の例外（旧耐震でも「―」）の理由。
