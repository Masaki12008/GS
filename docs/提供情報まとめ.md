# 若穂地区 小中学校再編検討 ― 提供情報まとめ

作成日：2026年10月27日（R8）

## 1. 検討の背景（最初にいただいた情報）

- 地域の少子化への対応を検討するため、住民説明会を予定している。
- 長野市若穂地区の小学校は、綿内小・川田小・保科小の3校。
- 当初の概数は次のとおり。※推計表の実数（下記3）に置き換えること。
  - 綿内小：全校約270名、1学年約2クラス
  - 川田小：約180〜200名、1学年1クラス
  - 保科小：全校約70名、2026年度（R8）の1年生は2人
- 今後さらに少子化が進むと見込まれる。
- 再編、統合、一部統合、現状維持などの選択肢から最適なものを選び、地域として長野市へ提言したい。
- 求めた支援：コンサルとして、スケジュール感の分かるロードマップを作ること。

## 4. 調べて補った情報（出典あり）

- **校舎の建築年度と、改修・更新の時期**
  - 出典：長野市学校施設長寿命化計画 添付資料（令和2年4月1日時点）
    https://www.city.nagano.nagano.jp/documents/1877/01gakko_betten.pdf
  - 川田小：1973年度築。更新時期は2023年度。
  - 綿内小：1980年度築。更新時期は2030年度。
  - 保科小：2010年度築。2030年度に築20年の改修。児童センターを併設。
  - 若穂中：1987年度築。2027年度に築40年の改修。
- **望ましい学校規模の目安**
  - 出典：長野市「少子化に対応した子どもにとって望ましい教育環境の在り方について（審議のまとめ）」（2018年）
    https://www.city.nagano.nagano.jp/n601000/contents/p004781.html
  - 国の標準：12〜18学級
  - 長野県の目安：学年に複数の学級があること、学年で20人程度を確保できること
- **若穂中の成り立ち**：昭和36〜37年に、綿内・川田・保科の3中学校が統合してできた。
- **市内の再編例**：信更小が閉校し、令和6年度から塩崎・篠ノ井西・信州新町の各小学校へ通う形になった。
