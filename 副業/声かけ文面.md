# 声かけ文面

最初の依頼は、知り合いからの紹介がいちばん取りやすいです。売り込むよりも「困っている人がいたら教えてほしい」とお願いする形にします。

## 1. 知り合い（PTA・自治会の役員経験者など）へ

```
［名前］さん、お久しぶりです。［自分の名前］です。

実は、地域の説明会の資料づくりを手伝う活動を始めました。
［若穂の学校の説明会］の資料を作ってきた経験を生かして、
自治会やPTAの「説明会資料」「総会資料」「お知らせ」を、読みやすく作っています。

もし周りで「資料づくりで困っている」という方がいたら、紹介してもらえると助かります。
最初の何件かは、お試しの価格（通常の半額）で作ります。

見本はこちらです：［BOOTHのURL］
```

## 2. 地域の団体（自治会長・PTA会長・公民館）へ

```
［団体名］［役職］様

はじめてご連絡いたします。［地区名］に住む［名前］と申します。
地域の説明会や総会の資料を、年配の方にも読みやすい形で作るお手伝いをしています。

・本文は大きな文字（16pt以上）、読みやすいUDフォント
・どの案も同じ扱いにする、中立的なまとめ方
・意見用紙や、回覧用のお知らせもあわせて作れます

資料づくりの担当になった方の負担を減らせればと思っています。
見本をお送りしますので、ご興味があればお知らせください。
```

## 3. SNS（X・Instagram・Facebook）の投稿例

```
自治会やPTAで「説明会の資料を作って」と頼まれて困っている方へ。

地域の説明会のためのPowerPointテンプレートを作りました。
・21ページ＋意見用紙・お知らせ
・大きな文字、UDフォント
・どの案も同じ扱いにする、中立的なデザイン

［BOOTHのURL］
#自治会 #PTA #パワポ #テンプレート
```

```
説明会資料で気をつけていること。
「もう決まっているんでしょ」と思われないように、
・題に結論を書かない
・今の形を続ける案も、同じ大きさで並べる
・特定の1つだけを赤で目立たせない

小さなことですが、参加する人の受け止め方が変わります。
```

※SNSの投稿文は、Claude に「声かけ文面を参考に、今週のSNS投稿を3つ作って」と頼めば毎週作れます。
