# 副業：地域の説明会資料（テンプレート販売＋作成代行）

目標：**2027年4月末（半年後）までに、月3万円の利益**。

| 収入源 | 単価 | 手取り（手数料を引いた額） | 月の目標 | 月の利益 |
|---|---|---|---|---|
| テンプレート販売（BOOTH） | 1,500円 | 約1,390円 | 8件 | 約1.1万円 |
| 資料作成の代行（ココナラ・紹介） | 8,000〜15,000円 | 約6,200〜11,700円 | 2件 | 約2万円 |

※手数料は2026年10月時点の目安です（BOOTH：5.6%＋22円、ココナラ：22%）。出品前に各サイトで最新の金額を確認してください。

正直な見通し：最初の2〜3か月は、売上がほとんど出ないのが普通です。評価が付き始める4か月目以降に伸びるかどうかが分かれ目になります。5か月目の時点で月1万円に届いていなければ、やり方を見直します（下の「見直しの目安」）。

## Masakiさんの作業チェックリスト

AI（Claude）が担当する作業には「AI」と書いています。それ以外は、ご本人にしかできない作業です。

### 第1週（11月第1週）：始める前の確認

- [ ] 勤務先の就業規則で、副業が認められているか確認する
- [ ] 若穂の説明会資料をもとにしたデザインであることを、委員会（または事務局）に一言伝えておく。地域のデータや名前は一切入れていない
- [ ] 売上用の銀行口座を決める（個人の口座でかまわない）
- [ ] 屋号を決める（例：「〇〇資料工房」）。本名を出したくなければ屋号で出品できる

### 第2週：BOOTH に出品する

- [ ] pixiv アカウントを作り、BOOTH でショップを開設する
- [ ] 商品を登録する：文面は `出品文面.md` の「1. BOOTH」、画像は `出品用画像/01〜05`、ファイルは `配布用/` の zip
- [ ] 自分で買う画面まで進んで、ダウンロードできるか確認する（購入は不要）

### 第3週：ココナラに出品する

- [ ] ココナラに登録し、本人確認を済ませる
- [ ] サービスを出品する：文面は `出品文面.md` の「2. ココナラ」、画像は `出品用画像/01`
- [ ] ポートフォリオに `出品用画像/02〜04` を登録する

### 第4週：最初の依頼を取りに行く

- [ ] `声かけ文面.md` を使い、知り合い（PTA・自治会・地域の団体）3〜5人に声をかける
- [ ] 最初の3件は「モニター価格」（通常の半額程度）で受け、レビューを書いてもらう

### 2〜6か月目：毎月やること（月4〜6時間）

- [ ] 依頼が来たら `受注の進め方.md` の手順で進める（下書きはAI、確認と連絡はご本人）
- [ ] 月末に `収支記録.csv` を付ける
- [ ] 月に1回、Claude にこう頼む：「副業フォルダの収支記録を見て、来月の改善点を3つ出して」（AI）
- [ ] 依頼で作った資料のうち、ほかでも使えそうな型を新しいテンプレートにして BOOTH に追加する（AI。依頼主の情報は必ず抜く）

## テンプレートを増やす候補（AIが作る）

売れ行きを見て、反応がよい分野から追加します。

- PTA・自治会の総会資料（議案書・会計報告・役員紹介）
- 回覧板のお知らせ（行事・清掃・防災訓練）
- 地域の行事の案内チラシ（夏祭り・運動会）
- 役員の引き継ぎ資料（1年間の仕事の流れ・連絡先表）

## 見直しの目安

| 時点 | 目安 | 届かないときの手 |
|---|---|---|
| 2か月目の末 | BOOTH で1件以上売れる | 画像・題名・価格を見直す。無料の見本版（3ページ）を出して入り口にする |
| 3か月目の末 | 代行の依頼が累計2件 | 声をかける先を増やす（市内の他地区のPTA・自治会、公民館） |
| 5か月目の末 | 月の利益が1万円以上 | テンプレートの種類を増やすか、代行の価格・内容を見直す |

## 守ること

- **確定申告**：会社員で、副業の所得（売上−手数料−経費）が年20万円を超えると申告が必要です。年36万円の目標なら申告が必要になります。20万円以下でも、住民税の申告は必要です。`収支記録.csv` を毎月付けてください。
- **ココナラの外で取引しない**：ココナラで知り合った依頼主と、サイトの外で直接やり取り・支払いをするのは規約違反です。
- **依頼主の個人情報をAIに入れない**：名簿・電話番号・住所などは、Claude に渡す前に「［氏名］」などに置き換えます。
- **中身の責任はご本人**：AIの下書きにある数字・固有名詞・日付は、納品の前に必ず自分の目で確認します。
