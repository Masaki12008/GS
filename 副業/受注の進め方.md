# 依頼を受けてから納品するまで

1件にかかるご本人の時間の目安：ベーシックで2〜3時間、スタンダードで3〜5時間（ほとんどが確認とやり取りの時間です）。

## 全体の流れ

| 段階 | ご本人 | AI（Claude Code） |
|---|---|---|
| 1. 相談 | 購入前のメッセージに返信する（下の定型文） | — |
| 2. ヒアリング | ヒアリングシートを送り、回答を受け取る | — |
| 3. 準備 | 個人情報を消してから、このリポジトリの `副業/案件/［案件名］/` に原稿を置く | — |
| 4. 初稿 | Claude に依頼する（下の依頼文） | 構成・スライド・意見用紙を作る |
| 5. 確認 | 数字・固有名詞・日付を原稿と照らし合わせる | 自分で見直した結果を一覧にする |
| 6. 納品 | PowerPoint と PDF を送る | — |
| 7. 修正 | 要望をまとめて Claude に伝える | 修正する |
| 8. 完了 | レビューをお願いする。案件フォルダから依頼主の情報を消す | ほかでも使える型を、テンプレート候補として残す |

## 定型文

**購入前の相談への返信**

```
お問い合わせありがとうございます。［名前］です。
［説明会の内容］の資料ですね。対応できます。

確認させてください。
1. 説明会の日にち（納品の希望日）
2. ページ数の目安と、お手元にある原稿・資料の形（Word・メモ・手書きなど）
3. 印刷して配りますか、スクリーンに映しますか（両方でも大丈夫です）

内容から考えると、［ベーシック・スタンダード］プランが合っていると思います。
```

**ヒアリングシート（購入後に送る）**

```
制作のため、次の質問にお答えください（わかる範囲で大丈夫です）。

1. 説明会の名前と、主催する団体の名前（表記のとおりに）
2. 日時・会場・参加する人（人数の目安・年代）
3. この説明会で、参加者にいちばん伝えたいこと（一文で）
4. 説明会のあとに、参加者にしてほしいこと（意見を出す・アンケートに答える など）
5. すでに決まっていること／まだ決まっていないこと
6. 使いたい数字と、その出典（資料名・時点）
7. 特に気をつけたい言葉や、避けたい言い方
8. 色の希望（みどり・あお・えんじ・その他）
9. 締切・提出先・問い合わせ先など、資料に載せる情報
10. 原稿・メモ・既存の資料（添付してください）

※名簿・住所・電話番号など個人の情報は、資料に載せるもの以外はお送りいただかなくて大丈夫です。
```

**初稿の納品**

```
初稿ができましたので、お送りします（PowerPoint と PDF）。

確認していただきたい点
・［ ］の部分は、いただいた資料にない情報です。わかれば教えてください
・数字と日付が、お手元の資料と合っているか
・言い回しで気になるところ

修正はあと［2・3］回まで承ります。ページ番号と直したい内容を、まとめてお送りください。
```

## Claude への依頼文

Claude Code でこのリポジトリを開き、次のように頼みます。［ ］を書き換えてください。

**初稿**

```
副業の案件です。副業/案件/［案件名］/ にある原稿とヒアリングの回答をもとに、
説明会資料を作って。

- 土台：副業/src/build_templates.js の説明会資料（色は［みどり］）
- ページ数：［15］ページ以内
- 出力：副業/案件/［案件名］/ に pptx と pdf
- 守ること：結論を先取りしない／どの案も同じ扱い／本文16pt以上／
  数字には出典と時点／わからない情報は［ ］で空ける（作らない）／年は和暦と西暦を併記
- できたら、PDFを画像にして見た目を確認し、文字のはみ出しを直して
- 最後に、原稿にない情報を使った箇所と、確認が必要な箇所を一覧にして
```

**修正**

```
副業/案件/［案件名］/ の資料を、次のとおり直して。
［依頼主からの修正点をそのまま貼る］
直したら PDF も作り直して、直した箇所を一覧にして。
```

**新しいテンプレートを作る**

```
副業/案件/［案件名］/ で作った資料から、依頼主の情報（団体名・地名・数字・人名）を
すべて抜いた汎用テンプレートを作って、副業/src/build_templates.js に追加して。
販売用の画像と BOOTH の文面も作って。
```

## 納品前のチェック（ご本人が見る）

- [ ] 団体名・会の名前・日付・曜日が、ヒアリングの回答と一字一句同じ
- [ ] 数字が原稿と同じで、出典と時点が書いてある
- [ ] ［ ］が残っている箇所を、依頼主に伝えた
- [ ] 特定の案だけが目立つ色・大きさになっていない
- [ ] PDF を開いて、文字が枠からはみ出していない
- [ ] ほかの依頼主の情報が混ざっていない
